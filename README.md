## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the development server:

   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Deployment

To deploy this portfolio, you can use Vercel (recommended):

1. Push the code to a GitHub repository
2. Create a Vercel account
3. Import the repository
4. Deploy!

Alternatively, you can build and export as a static site:

```bash
npm run build
npm run start
```
